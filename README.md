# Instagram Content Tracker

Веб-приложение для отслеживания прогресса контент-челленджа в Instagram: количество постов, подписчиков и оставшийся объём контента до годовой цели.

Личный pet-проект, сделанный для отслеживания статистики Instagram-аккаунта. Разработан с акцентом на экономию бесплатных лимитов внешнего API и устойчивость к "холодному старту" бесплатного хостинга.

Demo: https://marta-challenge.onrender.com

## Стек технологий

| Слой | Технология |
|---|---|
| Backend | Node.js, Express |
| Frontend | HTML, CSS, JavaScript (vanilla) |
| Данные из Instagram | Apify (Instagram Scraper Actor) |
| Персистентное хранилище | Upstash (Redis, serverless) |
| Хостинг | Render (free tier) |

## Архитектура: трёхуровневое кэширование

Ключевая инженерная задача проекта — получать актуальные данные из Instagram, не расходуя бесплатный лимит запросов Apify, и при этом корректно работать на Render free tier, который "засыпает" после 5 минут простоя (то есть in-memory кэш периодически обнуляется).

Решение — цепочка из трёх уровней:

1. **In-memory кэш** — самый быстрый уровень. Если данные в оперативной памяти сервера свежие, они отдаются мгновенно без единого внешнего запроса.
2. **Upstash Redis** — переживает "засыпание" Render. При пробуждении сервера сначала проверяется Redis: если там данные ещё актуальны, они подгружаются в память и отдаются клиенту — без обращения к Apify.
3. **Apify** — вызывается только тогда, когда данных нет ни в памяти, ни в Redis, либо они устарели. Свежие данные записываются одновременно в память, в Redis и отдаются на фронтенд.

```
Запрос → In-memory кэш свежий? ──да──→ Ответ клиенту
              │ нет
              ▼
        Redis свежий? ──да──→ Загрузить в память → Ответ клиенту
              │ нет
              ▼
      Запрос к Apify → Обновить память и Redis → Ответ клиенту
```

Такой подход держит расход лимита Apify под контролем и обеспечивает быстрый и стабильный отклик независимо от состояния Render.

## Переменные окружения

Создайте `.env` в корне проекта:

| Переменная | Назначение |
|---|---|
| `PORT` | порт запуска сервера |
| `ADMIN_SECRET_NAME` | секрет для принудительного обновления данных |
| `APIFY_API_TOKEN` | токен доступа к Apify |
| `UPSTASH_REDIS_REST_URL` | URL Redis-хранилища Upstash |
| `UPSTASH_REDIS_REST_TOKEN` | токен доступа к Upstash |
| `INSTAGRAM_USERNAME` | отслеживаемый аккаунт |
| `CHALLENGE_YEAR` | год челленджа |
| `START_OF_YEAR_POSTS` | количество постов на начало года |
| `START_OF_YEAR_FOLLOWERS` | количество подписчиков на начало года |
| `YEAR_GOAL_POSTS` | целевое количество постов за год |

Приложение осознанно **не запускается**, если обязательные переменные не заданы — это защита от случайного деплоя с недействительными или заглушечными секретами.

## Установка и запуск

```bash
git clone <repo-url>
cd <project-folder>
npm install
npm start
```

Приложение будет доступно на `http://localhost:3000` (или на порту из PORT).
